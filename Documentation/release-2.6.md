# KongScholar 2.6.0

面向两部书稿、一篇论文及教学指导的10项升级。继续使用本机离线资料库及灰白中性配色；KongFolio沿用文稿目录的0.22系列联动目标。

1. **自定义个人工作区**：左侧预设书稿写作、论文研究、教学、学生指导。自定义工作区可改名、增删页面并上移下移排序；最多20区，每区150页。未放入的页面从“所有工具”搜索打开，原记录不受影响。工作区是导航偏好，项目选择独立保留。
2. **个人资料录入模板**：“所有工具 → 个人资料录入模板”。预设《万国公报》文章、人物书信、士人回应及档案材料，可编辑、新建或删除。模板类型包括史料、文献、回应、论证、同行意见与札记，最多100份；预填出处、类型、核对事项或关联文献，原文与解释分开。新建表单也可选模板，覆盖同名已填字段前确认。应用模板后需自行填写标题，保存时仍验证关联与日期。
3. **长表单草稿恢复**：史料、文献、回应、论证、同行意见、札记及研究问题、回顾、审稿、指导会谈/稿次、研读课与备课表单，输入后约0.8秒保存独立本机草稿；离开或退出前再次保存，失败保留当前窗口。取消不删除草稿，重新打开同一记录另存草稿；“表单草稿恢复”逐项预览草稿与现有记录，再载入表单，正式保存后才写入研究资料。原记录已删可明确选择载入为新记录。独立草稿在数据目录editing-drafts中，最多100份、总32MB、单份4MB；未提交草稿不包含在完整JSON、迁移包或GitHub源码中。崩溃只能恢复已写入磁盘的草稿，最后不足一秒输入可能尚未保存。
4. **附件位置检查与批量重新关联**：“所有工具 → 附件位置与重新关联”。检查指导稿附件、本机PDF索引与KongFolio来源链接；书签可解析搬移位置。用户选择目录后查找内容相同的候选，预览原位置、新位置与验证依据，逐个勾选后再次核验并原子保存。相同记录只允许一个候选。PDF/附件核对内容指纹，KongFolio同时核对稳定文档编号；旧来源无指纹时明确标为仅文档编号一致，不补造旧指纹。每轮最多2000关联、20000目录项、读取512MB候选文件、展示2000候选；达到限制或目录无法读取会提示，结果不代表全部检查。原文件和旧索引内容保留。
5. **引文逐字差异核对**：“引文逐字差异核对”选择章节与脚注，比较插入时签名中的原文、出处、印刷页码与物理页码；逐字突出增删，保留标点空白，最多前2000字，完整原文仍可展开。旧签名不可解析时明确说明无法比较全文。可保留旧快照并记录理由，或手工填写当前原文中可逐字匹配的引文和引注，确认后更新脚注快照，保存前后快照与理由。正文中的引文不自动替换，须在写作台定位修改；冻结稿和交付稿不改写。原文未核对或选择保留旧快照时，原有提醒继续显示。
6. **书稿称谓与术语一致性**：“称谓与术语一致性”使用名称规范卡别名及自定义“规范名称 = 变体一 | 变体二”规则，提示作者行文中的用语与位置。中文引号、直双引号及以>开头的引文行排除；可为每章指定额外逐字匹配的引文排除片段，复杂嵌套须人工补充。规则最多500条，每条50变体；最多1000提示。仅提示，不自动替换历史原文或判断变体错误。
7. **章节修订集中处理台**：“章节修订集中台”并列本章同行意见、直接/论点关联的来源变更影响、脚注问题和未完成任务，打开对应记录或跳到引文复核；逐项保存已处理、暂缓、保留待核及理由。原意见/任务/来源复核仍有独立状态；集中台处理结论不替代这些状态。可变内容修改后，旧结论不自动算作本轮已处理。写作台新增本章修订与本项目交稿预览入口。
8. **按项目保存引注方案**：“引注样式与导出”分别保存每个项目的书籍/报刊/档案首次引用、再次引用和参考文献表，切换项目自动调用；未设置项目使用旧全局后备方案。预览后导出Word，当前正文与既有脚注快照保留；预览过期或样式有变须重新生成。此页与交稿排版页采用项目方案，旧冻结稿、历史交付和其他保留快照的导出沿用原稿次内容。
9. **书稿与论文交稿排版预设**：“交稿排版预设”为项目保存A4 Word字体、正文9—18磅、1—3倍行距、1.5—4厘米四边距、8—14磅脚注，以及可选独立扉页/作者、摘要、关键词和附录。提供书稿及论文快速预设；先预览内容再导出，真实连续页下注置于页底。空附加内容不输出，作者只在扉页勾选后输出。字体未安装时由Word回退，最终分页须按实际投稿要求核对；不宣称适配所有期刊。应用前述项目引注方案，不改当前正文。
10. **跨项目重复段落检查**：“跨项目重复段落”比较全部项目当前章节，列出两边项目、章名、段落和位置并可定位，人工记录合理重用、需要改写或引文/材料重复及理由。忽略空白、标点及脚注标记后至少30字、长度比例≥80%、三字片段相似度≥85%为候选；完全一致单列。共享章节不与自身比较。最多1500段、单段5000字、总100万字、15000对候选、200结果；跳过或达到上限明确提示，不能视为全书已查重。只比较本机稿件，不查询外部数据库，也不据此认定不当使用。

## 安装与资料保护

- 先在旧版导出完整JSON备份，退出旧版，再替换应用。支持macOS13及以上、Apple芯片与Intel。
- 2.6第一次保存将最低读取版本设为26，拆分存储升级为版本3。2.5及更早版本会进入保护状态；回退须使用升级前备份，不能让旧版继续写入新版库。保留数据目录中的archives；不要把索引文件单独当成备份。
- 正式资料、工作区、模板、项目预设和复核决定进入完整备份；未提交草稿、外部PDF和KongFolio原文件仍需另行保留。复核决定每类最多2000条；原记录、原稿、外部附件与历史冻结/交付快照保留。
- 本机自动备份和额外备份沿用既有设置，应用运行时按间隔检查；不上传研究资料。源码同步只包含白名单内源码、合成测试和版本说明，不含资料库、PDF、影像、学生资料、未提交草稿、附件或备份。
- 应用使用本机临时签名，尚未通过Apple公证。
