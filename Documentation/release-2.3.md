# KongScholar 2.3.0

发布日期：2026年10月24日。

## 本版十项功能

1. 专注写作：写作台按⌘⇧F隐藏侧栏、导航和接续卡，保留正文、脚注与证据。Escape退出；⌘⇧P进入项目快速切换。
2. 项目快速切换：工作台 → 项目快速切换，为各项目保存最近写作章节、光标选区、滚动位置、材料范围和检索词，或最近打开的史料 / 文献详情。点击“切换并继续”恢复；仅打开首页仍进入项目首页。保存失败阻止切换。
3. 阅读计划：资料 → 阅读计划，记录计划范围、已读范围、问题、下一步和下次PDF物理页。关联来自KongFolio的史料后可以请求继续阅读。使用文稿中的KongFolio 0.22.1联动补丁；按物理页打开时，KongFolio会要求确认页面。阅读进度由您填写，不自动推算。
4. 名称规范库：资料 → 人物与机构名称，分别记录规范名、别名、外文名和考证依据。全局检索及人物筛选可扩展为同一名称档案中的其他名称，不改写史料原文、署名或既有引注。
5. 历史日期范围：史料、事件、回应和概念用例可填写日期精度、起止日期及依据，支持确切日期、范围、不早于、不晚于和约年 / 推定。保留原公历日期、原纪年与日期说明；时间线区别显示，年代筛选按区间重叠检索。范围和推定日期须填写依据，不自动换算原纪年。
6. 来源与转引链：资料 → 史料来源与转引链，关联原刊、转载、译文、节录及后人转引，保留依据和疑点。可从材料向上游展开，发现循环或超过七层会提示，不自动合并同源材料或计为独立证据。
7. 研究问题演变：修改已有问题的标题或研究边界时须填写理由，可关联促成变化的史料。保留调整前后、时间、理由及当时依据摘录；从本版开始记录，不补造过去过程。
8. 整稿冻结：写作 → 整稿冻结版，一次冻结项目目录、章 / 节正文、脚注、论点与相关史料、文献和核对提示。后续修改不改变冻结稿；可以导出冻结稿Word或独立JSON，并把同行意见关联到该冻结稿。独立JSON是归档快照，不是完整备份；不包含外部PDF文件。
9. 交付历史：成功导出阶段 / 修订ZIP、写作Word或Markdown后记录收录清单、正文脚注快照和当时意见状态。接收对象与说明可事后填写；应用不会发送。可比较同一项目两次交稿或当前工作稿，显示章节收录、顺序、正文与脚注变化，以及较新状态下尚未回应的意见。“移出收录”可能只是未交该章，不表示资料已删除。
10. 选择性恢复：设置与工具 → 选择性恢复资料，读取本机快照或JSON完整备份，跨类型及项目选择记录，或选择现有记录的字段；新增找回记录须整条恢复。先预览差异并确认范围，应用再建立并校验恢复前快照，然后写入所选内容。预览过期、快照失败或写入失败均停止恢复。没有被选择的当前资料保留，缺失关联明确提示。

## 保存与边界

新数据均进入本机完整备份和自动快照，兼容旧版资料。每个项目最多100份冻结稿、300条交付记录，每个问题最多1000次调整；达到上限时提示整理，不自动删除。全部研究数据仍共享25MB文件上限。冻结稿和交付快照包含正文，增长较快，建议定期导出完整备份。

研究资料仅在本机。公开GitHub仓库仅发布APP源码、测试和版本说明，保留资料排除规则；没有GitHub凭证存入APP。自动备份仅在APP运行时检查，退出后不运行后台服务。

## 验证

23项Swift测试及15组JavaScript测试通过。新增覆盖日期区间、别名检索、阅读定位载荷、来源循环、问题依据快照、冻结稿独立性、成功交付记录、正文与脚注比较、记录和字段恢复、预览过期保护、快照失败及写入回滚、项目位置恢复和无效数据拒绝。

Mac隔离合成资料验收完成：专注模式、项目快切返回原章节、阅读与名称档案、日期与来源链详情、问题调整留痕、整稿冻结、实际导出Word并记录交付，以及单独恢复一条史料的原文字段。恢复前快照可读取，其他字段、问题证据快照和冻结稿均保留。Word样稿共四页，目录及各章顺序、两条真正页下注已逐页检查。未操作正式研究数据。

支持macOS13及以上、Apple Silicon和Intel。安装包为本机签名，未经Apple公证。升级前导出完整备份，退出旧版后替换APP。
