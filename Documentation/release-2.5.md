# KongScholar 2.5.0

2026年10月24日；macOS 13及以上，Apple Silicon / Intel通用版。延续随系统切换深浅色的中性灰界面。

## 本版20项

1. **今日工作台**：首页并列显示所有项目，书稿、论文和其他工作各自呈现上次位置、接续卡的下一段、今日任务估时和受阻事项。点击“切换并接续工作”恢复已有写作或资料位置。
2. **任务依赖**：工作台 → 任务依赖与受阻。编辑任务可勾选前置任务、填写受阻原因；未完成或缺失的前置事项会列出，循环关系阻止保存。完成任务前先完成前置事项并解除受阻原因。
3. **里程碑标准**：项目 → 里程碑完成标准。在完成清单每行填一项，完成项以[x]开头；仍有未确认项时不能通过编辑表单标记节点已完成。实际完成及证据由您核定。
4. **跨项目使用地图**：资料 → 跨项目使用地图。选择史料，对照各项目解释、限度及实际使用位置；可转到原有材料调度页填写独立使用说明，同一史料不复制。
5. **章节状态**：写作 → 章节状态总览。显示正文字符数、实际使用脚注、待核引文、未回应意见、原有定稿检查问题和最近修改时间，可定位回正文或意见。
6. **论证缺口**：写作 → 论证缺口与查证。集中检查支持材料、解释步骤、反证分析、适用范围及已填缺口，一组缺口可转为关联章节的任务，相同论点不重复建立任务。
7. **反向提纲**：写作 → 书稿反向提纲。逐段标记问题、材料、解释、反驳、结论或过渡，记录段落作用；锚点变化和重复时提示重新定位。每章预览前300段，正文完整保留，长章可按小节处理。
8. **概念语义比较**：资料 → 概念语义比较。按称谓、使用者、刊物和公历起止年筛选用例，并列原文、语境判断、其他解释与出处。显示前200条，导出保留本次全部匹配记录。
9. **人物交往**：项目 → 人物交往关系。先在名称规范库建立两位“人物”，再记录通信、合作、论争、翻译、荐举等事件，关联史料、日期依据和确定程度。每次事件单独留存，不由关系数量推断影响。
10. **研究年表**：项目 → 研究年表与书稿。并列史料形成、事件、回应及交往，按人物和起止年筛选，并返回已关联章节。范围、推定、不早于等日期标识保留；不详日期置后；筛选年份时排除完全无日期记录，单侧范围按可能重叠保留。显示前300条，导出保留全部结果。
11. **连续取证**：资料 → KongFolio连续取证。选择有原项目定位的史料及连续1—500物理页，逐页记录待核、已核或存疑，可返回KongFolio、截取本页影像。记录离开前保存，失败保留窗口；截取页的印刷页码重新人工核对，不沿用来源卡其他页的页码。仅读取原项目，沿用文稿目录KongFolio 0.22系列及其联动补丁。
12. **PDF全文检索**：资料 → 本机PDF全文检索。选择PDF或主动读取已关联的KongFolio项目，按物理页建立本机文字索引。普通文字层标为“PDF文字层（来源未核）”，不猜测是否来自既有OCR；无文字层页面可逐页补充“本机OCR”。搜索最多2000处、界面前200处，结果可导出并在APP的PDF核对窗口打开原页。文件变化会阻止使用旧索引打开，重新索引另存新记录。单PDF最多256MB、2000页，索引文字最多12MB。
13. **逐行OCR校订**：资料 → OCR图文逐行校订。影像与识别行并排，手工填写栏序1—20、同栏行序和疑字说明，按序重组校订稿。新识别行保留影像位置框，旧记录可能没有坐标。原始OCR不覆盖；已有整段校订不自动拆回行，须先核对。修改依据必填，离开前保存，失败或缺依据时保留当前修改；重组后为“待校”。每图最多2000行、300次校订。
14. **精细校勘**：资料 → 精细文本校勘。使用既有3—12版本组快照，选择底本与对校本，比较段落或单字，可忽略空白、标点和符号。每份比较前300段或2000字，完整原文仍保留。“独有”也可能源于改写或移动，须人工判断；比较选项不改写原文。
15. **变更影响复核**：写作 → 史料变更影响复核。从本版开始保存时记录原文、出处、文献关键字段、页码或定位变化，保留前后快照和当时受影响的当前记录。逐处填依据确认复核；不自动改写正文脚注、冻结稿、交付稿或校勘快照，也不把复核等同于引文已核对。最多10000条变更记录。
16. **引注样式**：写作 → 引注样式与导出。配置书籍、报刊、档案首次引用、同一文献再次引用和参考文献表；按项目正文顺序预览，再导出含连续真实页下注和参考文献的Word。调整仅用于本次导出，现有正文与脚注快照保留。缺失文献保留原引注并提示；样式仍须按投稿要求人工审定。
17. **Word批注接续**：写作 → Word返回稿批注。读取传统批注和所在正文段落，预览唯一匹配、多处匹配或未定位状态，可手工关联章节；明确选择后才加入同行意见收件簿。按文件校验值与批注编号去重，预览过期须重读。正文、脚注、修订痕迹和原Word不写入。现代线程批注、图片及修订内容须先在Word处理。单文件64MB、最多2000条批注。
18. **学期日历**：教学 → 学期日历与工作负荷。课次可填实际上课日期、正常 / 停课 / 调课、作业截止和备课估时，与已排任务、每周容量一起查看。停课不计备课，调课按实际日期；已把备课另建任务时请只在一处估时，避免重复。学生版计划附公开上课日历，仍省略教师反思和专用提示。
19. **指导两稿对照**：教学 → 学生论文稿次对照。选同一论文两份稿次，可带入较早稿意见和指定会谈的公开指导内容，保存独立正文与意见快照。逐项记录待讨论、部分解决或已解决及依据，导出下次准备。私人会谈笔记不带入，后续原稿修改不改写比较快照；正文比较显示前300段。
20. **完整迁移与演练**：设置与工具 → 迁移包与恢复演练。全部资料与历史收入迁移ZIP，外部指导稿件逐个勾选后核验收入；变化或缺失的所选原稿会中止导出。整包最多256MB、单附件64MB。演练验证成员、内容校验和资料结构，在所选位置建立全新独立目录、复制附件并重建链接，完成分拆写入与读回。通过后仍须另行预览导入，才可替换当前库；未打包附件仅保留原链接，需另行备份。保留演练目录及附件副本。

## 更新、保护与限制

先在旧版导出完整JSON备份并另行备份外部原稿，退出旧版再替换APP。本版首次保存将存储格式升级；2.4及更早版本会进入读取保护，不能继续写入本版资料。回退使用升级前完整备份。首次打开仍保留升级前快照。

索引与archives目录继续配套使用；自动与完整JSON备份会组装全部数据。新PDF索引只保存文字、定位与校验值，原PDF须自行保留；迁移包只复制勾选的指导附件，不复制全部PDF或KongFolio原项目。图像、研究记录、学生资料、审稿意见、外部附件和备份均只在本机处理，不上传GitHub。APP运行时执行备份，退出后没有后台备份服务。

公开GitHub仅发布APP源码、合成测试和版本说明。APP不持有GitHub凭证；发布连接失败时明确保留待同步状态，不宣称上传成功。

Mac安装包为本机签名，未经Apple公证。没有自动判断史料真伪、人物影响、语义转变、论证成立或学生成果质量的功能，相关判断及依据由研究者记录。
