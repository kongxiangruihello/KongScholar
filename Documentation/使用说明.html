KongScholar

1.9.0 · 私人学术工作台 · macOS 13 或更新版本 · Apple 芯片 / Intel 通用版

定稿与版本

在“定稿检查”集中查看缺失出处、印刷页码、来源变化、脚注缺失及正文占位文字，点击“前往处理”定位相关正文、脚注或史料；可以导出全部章节 Word。

在“章节版本”保存初稿、修改稿、送审稿等命名快照，对比正文和脚注增删。恢复前会自动保存当前稿，再恢复所选版本的标题、正文与脚注。版本包含在完整备份中，史料本身不回退。

人物与文本回应

为每条回应记录日期、发言者、对象文本、场合、身份称谓及证据，分别标记接触、转述、赞同、质疑、实践变化或待判断。可按人物与类型筛选、导出，类型由您的证据判断，不自动推定影响关系。

Word 与引注格式

章节写作台可导出当前章，定稿检查可导出全部章节。Word 使用 A4、中文正文与页下注连续编号；脚注保留人工编辑及复核提示。引注格式页支持按文献类型编辑模板，修改只用于新插入脚注，不覆盖旧脚注。

章节写作台与脚注

从左侧选择章节，在中间撰写正文，右侧查看本章论证及支持、反证史料；也可切换全部史料。将光标放在正文后，插入摘录与脚注或仅插入脚注。正文自动保存，也可手动保存；离开页面或退出前会尝试保存，失败时保留窗口。

脚注采用 Markdown 标记，可编辑脚注草稿并导出正文与脚注。脚注保留插入时的出处快照，来源变化后提示复核；缺失出处、页码或未核对状态会在导出时保留提示。本版可导出 Word 正文与真正的页下注，并提供可编辑的书籍、期刊、档案引注模板。仍需按目标期刊要求人工审定格式。

导入历史与撤销

从 1.3 起，每批 KongFolio 导入同时记录前后快照，包含在完整备份中。预览撤销后确认：未修改且未被使用的新增卡片可移除；已修改或进入写作、论证、教学的卡片保留。更新按字段恢复，之后独立改写的字段保留；同一卡片存在后续导入时，先撤销后续批次。历史与正文共享本机 25 MB 数据上限，请定期备份。

文献档案与引文核对

在文献档案保存作者、刊物、年代、卷期、版本、译编者及作者归属依据，再编辑史料选择所属文献。印刷页码与 PDF 物理页码分别填写；KongFolio 来源的物理页码以联动记录为准。

引文核对由您对照原文后人工确认。文献、原文、页码或来源文件变化后会提示需复核；个人解释独立保留。可按章节导出核对清单。界面随系统切换深浅色。旧数据与备份继续使用，建议更新前导出完整备份。

明确绑定文稿中的 KongFolio

本版修正文稿目录 KongFolio 0.22 的联动：默认目标是 ~/Documents/KongFolio.app，不再从同名运行实例中挑选旧版。请使用以文稿 0.22 为基础的 0.22.1 联动补丁，并在“文件 → 选择 KongFolio App…”确认路径。联动页面会显示目标路径、版本和是否可用。

0.22 的原始 Markdown 摘录可直接导入；精确回到原批注需要 0.22.1 保存的稳定文档编号。新版格式 4 项目与旧格式均可重新关联；PDF 页码标签作为待人工核对的印刷页码，书目资料预填出处。此前 0.4 / 0.5 联动构建不应覆盖文稿中的 0.22。

1.9 新增：全局检索与资料整理

  • 全局检索：全库搜索记录、章节正文、脚注与接续卡，按项目、类型、人物字段和公历年代筛选，显示命中片段并打开位置。不扫描外部 PDF / Word。
  • 资料收件箱：零散摘录先临时收存，可归入史料、札记或任务。原收件及归档目标链接保留，不会重复转入。KongFolio 结构化导入预览提供“先存收件箱整理”，保留稳定批注和定位，归档时复用原有导入与冲突检查。旧版 Markdown 仍走原导入流程。
  • 重复与关联检查：相同摘录、同名同署名文献作为候选，不自动合并。可预览主记录与并入记录；主记录非空字段优先，个人解释 / 辨析并列保留，项目归属合并，原记录及关联变更留存。不同原批注或相反证据角色会阻止合并。脚注文字和历史稿文字不改写。
  • 恢复入口：合并后未有独立修改时，可恢复原记录与关联；若已有修改，完整恢复会中止，可仅恢复被并入的原记录，保留当前引用与修改。备份包含合并快照。
  • 项目回顾：从 1.9 开始记录新增、修改、完成等活动，不倒推旧资料完成日期。最多保留最近 10000 条活动；五分钟内连续修改同一记录合为一次变更。按周生成摘要、当前待办和下周已有安排，再由您补充判断、问题与计划，可保存和导出 Markdown。

收件、合并恢复记录、项目活动与回顾都进入完整备份和快照。合并不是原文校勘；异本与不同语境的相同文字通常应保留独立记录。

1.8 新增：项目节奏与写作推进

  • 本周工作台：按当前项目范围查看周一至周日，选择未完成任务重新安排，保留原日期、调整时间与原因。手动编辑安排日期、加入或移出今日也会留痕；历史从 1.8 开始记录。
  • 项目里程碑：书稿可建立目录确定、章节初稿、全稿修改、送审节点；论文可建立初稿、投稿、返修。节点关联任务，目标日期、完成标准、完成日期及说明由您填写；不根据任务数量自动认定完成。
  • 写作接续卡：在写作台记录上次位置、下一段判断、待补材料，可把光标前文字记作位置并关联待用史料。自动保存，切换和退出前检查保存结果。写作接续页可跨章节查看。
  • 跨项目资料使用追踪：选择文献或史料，查看全库项目、记录、当前脚注与历史版本使用。首次打开建立变化基准，之后来源或书目信息变化提示复核。记录已查看不会更新旧脚注或历史版本；正文脚注有差异时仍提示复核。

新节点、接续卡、安排历史和复核记录均进入完整备份与快照。历史快照差异不等于原稿有误，仍须人工判断；应用不自动改写历史材料和判断。

1.7 新增：多项目工作台

今日工作台汇总全部项目的今日安排、正在推进的项目及其他学术工作。首次升级将旧资料保留原编号并归入原课题书稿；另提供“第二部书稿（待命名）”“论文（待命名）”“其他学术工作”三个可重命名的项目框架，均无虚构研究内容。

  • 学术项目：编辑项目类型、阶段、截止日、近期目标、下一步与说明。已有资料归属的项目有删除保护。
  • 项目工作区：通过工作范围选择一个项目，查看其研究问题、章节、论证、写作与任务；可直接进入章节写作、定稿检查及研读课。
  • 每条记录可关联多个项目。共享文献、史料保持同一编号；引用资料时可访问全库，避免重复录入。记录的“项目归属”与文献的原项目 / 馆藏字段不同。
  • 任务支持研究、写作、备课、审稿、会议报告、学生指导等类型，可记录截止日与安排日期。首页从待办加入今日，手动上下排序、标记完成，或移出今日而保留任务。
  • 今日安排始终跨项目显示。各模块的项目范围用于浏览，完整备份、快照和写入始终包含全部项目。

未安排完成的昨日任务保留原日期，仍可在待办中重新加入今日，不自动移动。无项目归属的记录可在“全部项目”查看。项目为资料组织方式，不是访问权限隔离。

1.6 新增：概念辨析与章节推进

  • 历史概念卡：每个用例分别记录称谓、使用者、公历年代、原纪年、具体用语、语境、竞争解释与史料。可按称谓筛选和并列比较，导出比较记录。
  • 文本与回应对读：选择林乐知原文史料和已有回应记录，展示双方证据与出处，编辑措辞变化、共同问题及解释限度。原文身份由您核定，应用不自动识别作者或推断影响。
  • 章节论证推进：集中显示核心问题、当前判断、支持、反证和出处核对缺口，可逐项转为任务并进入章节写作。
  • 史料研读课：填写教学目标、背景、讨论问题、课堂流程、作业与教师提示；选择史料后可上移、下移调整阅读顺序，分别导出 HTML / Markdown 学生版与教师版。HTML 可在浏览器打印或存 PDF。学生版不导出教师提示字段；请自行检查其他公共字段是否适合发给学生。

四个工作区的数据均包含在完整备份和本机快照中。没有预置虚构史料或历史判断。已有材料改动后，对读和研读课展示最新资料，已经导出的文件保持导出时内容。

1.5 新增：可靠联动与资料安全

  • 联动设置中心显示完整目标路径、版本、最近导入和返回请求，可检查项目文件及文档编号。
  • 备份中心提供每小时本机快照、版本升级前快照、手动快照与校验。关闭应用期间不执行定时备份。自动快照保留最新 60 份；备份与当前数据在同一 Mac，请继续另存重要备份。
  • 恢复演练只打开数量预览，关闭即可退出；确认恢复时会要求另存当前快照。PDF 与 KongFolio 项目需单独备份。
  • 文献衔接按项目显示书目差异，已有档案字段默认不勾选，逐项确认后再合并。来自旧导入的书目信息请从 0.22.1 重新发送摘录。
  • 研究任务可从定稿检查、章节证据缺口、回应记录缺口建立，关联原史料、章节与回应，进度支持待办、进行中和已完成。

安装与打开

打开磁盘映像，将 KongScholar 拖入 Applications（应用程序），再从应用程序启动。此构建采用本机签名，未作 Apple 开发者公证。如果系统限制启动，请通过系统“隐私与安全性”界面处理；应用不会修改系统安全设置。

KongFolio 联动

安装并各打开一次 KongScholar 1.9.0 与 KongFolio 0.22.1，并确认文稿目录中的 App 路径。KongFolio 保存项目后，从“KongScholar”菜单发送摘录；此处检查预览再导入。也可从“文件 → 导入 KongFolio 摘录…”（⌘I）选择结构化 JSON 或旧版批注 Markdown。来源原文和来源批注与个人解释分开，更新保留研究问题与论证关联。史料卡片可“返回原文”或“重新关联项目”。印刷页码需人工核对；页面重排、批注删除与文档变化会提示核对。备份不携带原 PDF 或项目文件，跨 Mac 迁移时需另迁项目。

离线使用

界面和功能已打包在 APP 内，无须登录网站或运行本地服务器。围绕“何以为士：林乐知与晚清士大夫的重塑”，可使用研究问题、史料卡片、论证卡片、章节证据清单、原文对读、时间线、写作、教学和札记。框架中的待检验问题不等于历史结论。

从网页版迁入

  1. 在原网页版“备份与恢复”中导出完整 JSON 备份。
  2. 在 Mac 版选择“文件 → 导入 JSON 备份…”（⌘O）。
  3. 检查恢复预览中的数量和研究方向，勾选确认。
  4. 选择一个位置保存恢复前快照。取消保存会中止恢复。

支持旧版“史序”及 KongScholar 备份。浏览器和 Mac 版不自动同步；导入将替换 Mac 版当前记录，不会修改网页版记录。

数据与备份

记录写入 ~/Library/Application Support/KongScholar/scholar-data.json。每次成功替换前，上一份文件保存在 recovery/previous-data.json；这只保留一个上一版本，不代替您主动导出的备份。通过“文件 → 显示数据文件夹”查看。不要在 APP 运行时手动编辑数据文件。

“文件 → 导出完整备份…”（⌘S）可将 JSON 保存到您选择的位置；单条记录与章节清单可导出 Markdown。只有文件成功写入后才记录备份时间。应用保存在 Mac 用户账户内，没有另外设置密码或加密，不会自动上传记录。

常用快捷键

  • ⌘N：新建研究问题
  • ⌘O：导入备份
  • ⌘S：导出完整备份
  • ⌘+ / ⌘− / ⌘0：调整与还原文字大小
  • ⌘W：关闭窗口；点击 Dock 图标可重新显示
  • ⌘Q：退出

KongScholar 2.1 书稿与论文推进

项目 → 书稿与论文目录：选择一个项目后管理章、节，上下移动调整同级顺序，更改上级建立嵌套结构，最多七层。子节跟随上级整体移动。状态按项目手工标记；篇幅为正文非空白字符数，不计脚注标记。未保存过目录的旧章节直接显示，首次调整才保存顺序。写作提纲及当前项目的全部章节导出沿用目录顺序。已缺失或移出项目的目录位置保留并提示，可移除失效目录项，子节提升一级。

写作 → 论点与证据矩阵：按目录并列问题、论点、支持、反证、解释限度与待补事项。可以打开章节、添加论点、查看关联史料。不根据材料数量判定论证成立，尚无反证也不表示不存在反证。

资料 → 跨项目材料调度：全库选同一条史料，分别为每个项目保存解释和使用限度。按项目显示实际使用位置，可返回正文、论证或其他使用记录。说明与原文及脚注快照分别保存。离开、切换和退出前保存待存说明；保存失败保留缓冲并阻止离开。共享史料合并时，同项目不同说明会附上合并标识保留。完整备份包含目录、状态和全部项目使用说明。

写作 → 阶段成果包：选择一个项目后生成预览，确认导出为一个ZIP。包括静态目录、Markdown正文、Word正文（真实页下注）、引注检查、待解决问题、论点证据和本项目材料使用说明，共七份Markdown及一份Word。无正文章节时仅导出规划清单。Word沿用每章/节另起一页的格式，目录没有自动页码；Markdown脚注分章节编号，避免同号脚注互相覆盖。预览后资料变化须刷新。成果包不是完整备份，只包含当前项目的使用说明，分享前请阅读包内内容；不会自动发送或上传。

## 同行讨论与修订

- 意见收件簿保留意见原话、作者判断、决定、理由和回应。每条意见对应一个项目，可关联章节、论点、史料及保存版本。未绑定版本时仅记录手工稿次名称，不自动保存当时正文。
- 接受或部分接受的意见可转为修订任务，重复操作打开已有任务；按项目调整顺序和日期，完成时须填写修改说明。任务完成与意见已回应分别记录。
- 修订稿交付包增加总体修改说明和意见回应表；可选择是否包含意见原话、待解决问题及论点证据、内部材料使用说明和个人札记。默认不包含后三类内部材料，引注检查始终保留。
- 交付包可逐项预览后导出ZIP，不自动发送。交付页稿次、总体说明和选项是当前会话草稿；正式修改说明请保存在意见和任务中。

## 本机自动备份

设置与工具 → 备份与恢复，可选15、30、60或120分钟检查间隔，默认60分钟；保留30、60或120份自动快照，默认60份。APP运行时每分钟检查是否到期，首次保存、关闭窗口或退出前也会检查。内容未变化时不重复创建自动快照；手动和升级前快照保留。备份中心显示最近可读取快照和错误状态，可预览恢复。

备份仅在APP运行时执行，APP退出或电脑关机后不继续后台运行。研究资料只在本机保存，本版不提供跨设备资料同步。
