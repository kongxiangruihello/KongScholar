# KongScholar 3.3.0

2026-10-25 · 第30次构建 · macOS13+ · Apple芯片 / Intel通用版

1. **个人学术工作台**：左侧KongScholar下方统一显示“个人学术工作台”，下一行明确当前项目。窗口页面标题及关于说明同步更新。
2. **更紧凑的左侧菜单**：五个主要入口加入灰色线条图标，当前区域的常用工具直接列在左侧，减少原来右侧横排工具占用。菜单采用较小行距、当前页底色和区域分隔，工具较多时只滚动菜单，左下备份区保持可见。“今日工作”增加学术项目入口，个人工作区及全部工具搜索继续保留。配色继续使用中性灰白，并按系统深浅外观切换。
3. **明显可用的自动备份**：在原有定时快照上增加左下常驻状态、最近快照时间、立即备份、设置与恢复。原生状态接口只读取文件元信息，避免为显示状态反复组装整个资料库；约每分钟刷新。新资料库、未设间隔的旧资料默认15分钟；已有15/30/60/120分钟选择原样保留。首次保存后也会检查并建立快照，运行期间约每分钟检查是否到期；退出前继续检查。无变化内容跳过重复自动快照，手动和升级前快照保留。立即备份先保存正文和正式资料，再建立并校验快照；保存失败则停止备份请求，备份异常在左侧显示。自动快照仍可选择保留30/60/120份，不在退出APP或关机后后台运行。
4. **当前阶段下拉选择**：编辑学术项目时，可选择待规划、选题构思、资料搜集、史料研读、提纲设计、初稿写作、修改完善、送审投稿、出版准备、备课准备、教学实施、指导进行、审稿进行、报告准备、已完成、暂缓。以前手填的其他阶段自动作为当前选项保留，不因打开编辑而被替换；切换阶段不自动修改正文、项目类型或任务状态。

## 返回稿与逐项回复

12. **Word文字修订接续**：书稿/论文 → Word文字修订接续。读取本机DOCX正文段落中可辨认的插入、删除、作者及时间，分别显示该段局部修改前后文字。确认稿次、勾选修订并人工选择章节后，接入同行意见收件簿，仍为待判断、待处理；重复读取同一文件同一修订不重复建立记录。读取和接入均不改写Word或章节正文。传统/新式批注沿用原入口，亦可转入当前返回稿的文字修订页。

仅支持主文档段落中的文字增删。移动、表格内修订、格式与段落标记变化、绘图/文本框等单列未接续提示，不声称还原完整修订前后文件。含脚注或域等复杂内容的修订另提示须回Word核对。XML上限12MB、2000条文字修订、20000个段落、嵌套256层；重复的上下文总量另限12MB，超限拒绝而不截断导入。异常XML及DTD/实体声明拒绝读取。实现依据Microsoft的[插入文字定义](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.insertedrun)及[各类修订说明](https://learn.microsoft.com/en-us/office/open-xml/word/how-to-accept-all-revisions-in-a-word-processing-document)。

13. **审稿逐项回复材料**：同名页面逐项选择原意见，填写对外回复、接受/部分接受/暂缓/不采纳、修改章节、唯一原文片段、位置说明及采用证据。接受或部分接受并标为已核时，原文片段须能唯一定位于当前正文。原意见、正文或证据后改后提示重新核验；全部已登记回复核定后，才能导出当前项目的Word/Markdown回复材料。材料固定当时原意见、对外回复、修改片段及所选证据的出处摘要，不自动带出内部判断、反证分析或处理理由，也不会自动改变原意见的回应状态。作者须自行检查对外回复中主动填写的内容。导出沿用交稿记录与待补记回执保护；未登记回复的其他意见不自动纳入。全库最多2000条回复，每条最多100次历史，对外回复50000字以内。

## 写作、识读与版本核对

14. **正文与脚注即时预览**：章节写作台 → 显示正文与脚注预览。编辑正文后约0.18秒更新，按首次出现顺序排列本章脚注，重复标记沿用注号，缺失脚注明示；切换预览不改正文。预览上限80000字符、200条不同脚注，每条出处显示最多2000字符，超限明确提示，实际编辑与导出不因此截断。图表暂显示正文标记，不模拟Word分页与最终页下注布局。

15. **个人识读词表与候选**：资料 → 个人识读词表与候选。按项目登记人名、刊名、旧称、常见误识和核定依据；可在现有文字中查找登记的误识字串，或明确点击后将该项目词表用于一次本机影像识读。新识读结果单独展示，填写采用依据后才写入校订稿，标为待校并保留原始OCR与修改前后历史；史料原文和原图保持。未采用候选仅在当前会话中暂存。词表识读会启用系统语言校正，可能改变旧字词，不能据此视为逐字校准；旧的无词表识读路径保持。此选择依据Apple说明：[customWords在关闭语言校正时不生效](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/customwords)。全库最多500词、每词80字符、总UTF-8文本32KB；查找最多500处，每次展示100处。

16. **跨版本页码对应**：资料 → 跨版本页码对应。选择同一项目的两个不同PDF，逐行填写“左物理页 | 右物理页”和核定依据，可登记一页对应多页。按登记的页对分别打开两版原页；没有登记的页面不推算、不插值。对应表固定两个PDF的内容指纹，重建或更换PDF后旧表保留并停止沿用，应另建新表。全库最多500表，每表最多2000组页对，物理页上限2000且须在实际文件范围内。PDF文件仍需自行保留；普通JSON只包含关联与对应表。

17. **逐条引文文本层选择**：书稿/论文 → 逐条引文文本层选择。针对单条脚注分别选择原文、标点整理、通行字或个人释读，填写采用依据；引用须出现在所选文本层，整理层另须已有史料整理依据。新引文可以连同摘录插入正文；既有引文换层只更新该脚注的快照，正文引用文字须自行修改。史料的默认引用层不随单条选择改变。当前所选层后改会提示复核，修改默认层或未选层不误报。逐条选择与史料快照进入交稿历史，整稿冻结版保持冻结时的脚注选择，不借用后来的当前脚注。首次插入仍待逐字核对，人工勾选后才标为已核。

## 研究现场与独立窗口

2. **研究现场组合**：今日工作 → 研究现场组合。将一个项目的研究问题、论证卡、章节、资料和一份PDF的物理页码保存为具名组合，另记继续解决的问题。可更新为该项目最近保存的正文光标与PDF位置；重开时先切换项目并恢复章节，再独立打开指定PDF页。正文位置依未改写段落编号恢复，原段落改写后回到章节开头并提示重新记录；PDF内容指纹变化或关联缺失时停止自动恢复，要求人工核对。它引用当前材料，不是整套材料的历史冻结。
6. **独立阅读和写作窗口**：书稿 → 独立写作窗口与草稿，写作台亦有“独立窗口继续本章”。每章一个独立正文窗口，最多同时20个；主窗口可继续阅读或处理其他章节。原文摘录、出处与个人解释可从研究现场独立查看，只读快照须重新打开才能看到后续修改；PDF沿用独立原页窗口。独立写作约0.6秒写入本机草稿，点击“保存到章节”后才成为正式稿；保存期间暂停输入，主稿或脚注后来改变时拒绝覆盖并保留双方文字，可另存窗口文字核对。关闭可保留草稿，重开后从草稿列表恢复；退出APP会尝试逐窗保存，发生冲突会阻止退出。

独立窗口是纯正文编辑，脚注与图表的文字标记会保留，脚注编辑仍在主窗口完成。普通章节版本恢复正文标记；需要固定当时图像和表格时，应建立整稿冻结版。

## 实际 Word 插图和表格

8. **Word真实插图**：书稿/论文 → 正文插图与学术表格。先在图表目录登记图像原件、图号、独立的实际导出图注、来源说明与宽度，再向所选章节插入单独一行的图像标记。Word导出替换为嵌入PNG、图题、图注和来源，内部放置计划不输出；缺失原件、无来源、尺寸不合法或跨项目标记会停止导出。真实文件检查显示实际嵌入数量。新整稿冻结版固定当时图像字节及图注，后改图像不回写旧冻结稿；旧冻结稿缺少自己图像快照时拒绝借用当前图像。
9. **可编辑学术表格**：同页建立表格，填写项目、独立表号、表头和数据、表注与来源。使用Tab分列、换行分行，输入区可直接按Tab。Word生成原生可编辑单元格，浅灰表头、细边框、跨页重复表头；短表尽量整组排版，较长表可跨页，末行与说明相接。表格最多100行含表头、12列，每格5000字以内，须各行列数一致；原生导出另限制总文本2MB。没有合并单元格、公式计算或自动图表编号。

插入位置使用最近保存的正文光标，未记录时放到章末；标记须保持单独一行，移动标记即可调整输出位置。PNG单张最多8MB、6000×6000像素，宽2—16厘米且须放入当前页边距，高不超过22厘米；整份导出最多100处图表、图像合计64MB、Word总量256MB。正文、脚注、图表及实际导出快照继续进入交稿记录与独立回执保护。Quick Look仍可能省略页下注和分页，最终版须保存后人工核对。

## 书稿索引与返回批注

10. **人物与概念索引**：书稿 → 书稿索引工作台。登记人物、刊物、机构、概念等规范词及别称，逐处检查正文中的字面匹配，可排除误匹配并导出位置清单。人工确认当前候选和排除位置后才向Word写出XE标记和INDEX域；正文、段落顺序、章名或词表改变后必须复核，或暂停该词输出。候选每页50处、每章最多5000处，达到上限拒绝确认/导出；重叠位置采用较长词，仍须人工拆分词表核对。当前只扫描正文段落，脚注、图注、表格内容及附录不自动建立索引。APP不计算最终索引页码，请在Word中更新索引域；排版软件对域的支持可能不同。
11. **新式Word批注与回复**：沿用Word返回稿读取入口，在传统批注正文基础上读取回复父子关系、线程起点、Word解决标记、稳定编号及扩展时间，并显示各部分是否可读。回复继承所属意见的正文锚点；缺失父批注时提示，不推造关系。接入前仍须确认稿次/关联范围并勾选意见；Word“已解决”不会自动把作者回应状态改为完成。缺少扩展信息时继续显示可读取的传统正文，并标明边界；目前不读取修订痕迹、附件、提及通知或云端会话，也不回写Word。文件上限64MB，最多2000条批注；异常XML、循环关系等会拒绝读取。

批注实现依据Microsoft公开格式说明：[回复关系与解决标记](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-docx/9660dacc-2ceb-4352-87d2-42ba1184f522)、[稳定编号](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-docx/9c360cd7-653f-4d82-82be-7bda2488c0c1)、[扩展时间](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-docx/a7b57225-42e5-43e7-8d98-d90eabf3ca25)。不同Word文件提供的信息可能不同。
