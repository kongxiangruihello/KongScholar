# KongScholar 3.9.0

面向个人著作、论文、讲座与研究工作。本版集中完善研究依据、可追溯判断、结项整理及跨Mac迁移。

1. 章节研究包固定快照：保存当时问题、观点、所选原文、出处、解释与文献档案，逐项比较原资料变化，导出固定版本。
2. 补证任务：逐条勾选待补材料和出处缺口，预览后生成关联项目、章节与材料的任务，同源去重，可返回研究包。
3. 线索与章节关系：按线索、问题、论点、章节组织已有关系，点击聚焦，提示未接入论点或章节的问题及缺失节点。
4. 进展修改历史：修改已有日志必须填写理由，保留前后版本、时间；恢复旧判断追加历史。3.9以前未记录的修改不能补造。
5. 结项项目归档：已结项或暂缓项目可退出日常工作台、今日任务和日历；归档区可检索只读资料、成果，说明后可恢复。完整备份始终保留。
6. 跨时区核对：月历、周历及重叠按当前Mac时区换算，同时显示原时区；导入的明确时刻保留，支持夏令时重复时间准确往返。手工不唯一或不存在的时间提示待核。
7. 学术进展简报：从带来源快照的私人周报逐项选择，默认仅时间范围。卡点、内部摘要、未选资料及稿件正文不自动带入。编辑保存后可导出Markdown。
8. 新Mac迁移向导：完整库和所选附件打包，在长期本机目录独立恢复，核对新PDF/附件路径与KongFolio绑定，再打开数量与差异预览，保存恢复前快照后导入。

## 数据与兼容性

最低macOS 13，Apple Silicon和Intel通用构建。3.9写入后最低读取版本39、归档格式15；旧版应进入升级保护，不应继续修改新库。升级前的完整快照保留。新增快照、修改历史和简报来源随完整备份保存，存储使用内容寻址归档。原有教学资料只读保留，不进入个人学术流程。

KongFolio继续使用用户选定的文稿目录0.22.1联动版；迁移检查只读取绑定信息与文件身份，不启动应用，不自动选择同名应用。迁移包沿用最多200个关联、单文件64MB、总256MB的限制；未收入的外部文件保留原关联，缺失会提示。独立表单草稿需另用含草稿工作备份。

资料只在本机备份。GitHub仅同步APP源码、合成测试及版本说明。导出简报只保存本机文件，不发送。日历不写入系统或云端，不做在线同步。

构建为本机临时签名，未完成Apple Developer ID签名及公证；Intel版本为交叉编译验证，未在实体Intel Mac实测。

## 验证

自动验证覆盖固定快照、材料变化、预览过期、保存失败回滚、补证选择与去重、历史恢复、归档原稿保全、简报选择隔离、时区跨日重叠、夏令时不存在与重复时刻、原时区拖动、迁移后路径核验、归档15完整备份与独立恢复。发布验证报告另随安装包提供，记录实际测试结果。
