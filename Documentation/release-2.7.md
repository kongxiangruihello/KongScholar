# KongScholar 2.7.0

落实上一轮30项建议中的第一阶段（第1—8项），先加强资料保护、恢复、性能与发布流程。第9—30项留待后续版本。

1. **升级前专用备份**：首次写入2.7资料前，在数据目录upgrades中保存升级前的独立完整JSON，读回比较并保存校验回执；失败阻止写入。本版本第一次保存独立草稿也会先完成资料格式升级保护。专用备份不参与普通自动快照的数量清理。新资料库单独标识为没有旧资料；同一版本的不同资料目录各自建立回执。回执或原升级备份损坏时，新会话不会跳过核验。
2. **启动自检与故障说明**：启动时检查索引、历史归档、必要记录结构、项目预设结构、独立草稿、升级备份和界面资源；“所有工具 → 启动自检与升级保护”显示结果并可重新完整检查。界面另行校验资料字段、项目预设内容及记录本次脚本运行错误。读取失败时进入保护状态，显示具体原因并阻止空数据覆盖原件。明确选择恢复且成功导出当前原始数据后，可先保全损坏原索引再恢复完整备份；原归档继续保留。损坏原件保全不等于一份可恢复JSON，检查会明确提示，须另外保留原数据文件夹。
3. **表单草稿历史**：“表单草稿恢复”现在先显示概要，选择一份后按时间点比较所选草稿、最新草稿与正式记录。每份草稿保留最近20个有内容变化的历史版本，历史总量最多8MB，达到限制淘汰更早版本；单份草稿当前内容最多4MB，含历史文件12MB，100份草稿总96MB。恢复只载入表单，仍须正式提交；提交后清理本次对应草稿及历史，其他独立草稿保留。输入约0.8秒保存，未写入磁盘的最后输入可能无法恢复。
4. **草稿可选纳入备份**：“所有工具 → 含草稿的工作备份”。可勾选将未提交草稿及其历史收入工作ZIP；不勾选则不读取草稿。包内正式资料与草稿分别校验、分别恢复。正式资料先进入差异预览；草稿明确勾选后作为新编号副本导入，不覆盖已有草稿和正式记录。可在另一台Mac导入后继续编辑。ZIP总上限256MB，外部PDF、KongFolio和稿件附件不在本工作包内，仍需另行备份；旧完整JSON和迁移包保留原流程。
5. **备份差异预览**：完整JSON、本机快照及工作包的正式资料恢复，都列出新增、内容不同和当前有但备份中缺失的记录，显示章节正文字符数量变化、偏好与附加设置差异。记录每次显示30条，展开后才绘制字段对照，长字段预览保留截短提示。整体恢复会替换当前库，缺失记录不会保留；需要保留时使用既有选择性恢复。预览后资料或恢复内容变化会拒绝执行；实际恢复前仍须成功保存当前快照。只比较内容，不判断哪份更正确。
6. **GitHub源码待办与回执**：“所有工具 → 源码同步与发布回执”展示本版本、仓库、白名单文件数、源码清单校验值、待同步/未完成/已核验状态及失败原因。开发工具Tools/publish-source.py自动生成离线源码队列；使用已有gh登录发布时，读取新鲜主分支、建立非强制提交、核对并发修改，再回读分支及逐文件Git内容校验值，全部通过才生成成功回执。重试发现同样源码已发布时可核验已有提交。APP不保存凭证或发起资料上传，导入回执须与本版本及清单相符；显示的是工具留存结果，APP不会再次联网验证。源码包和安装包完成不算远端同步成功。
7. **长书稿性能**：减少保存过程中重复读取与校验整库及重复自动备份调用，将来源变更比较中的来源/文献查找改为映射查找。章节版本每次显示20版，只有明确选择两稿后才比较，对照每次300行、单行前2000字，完整两稿正文与脚注可另行导出。草稿列表只传概要，历史和字段展开后读取/绘制。没有丢弃历史或缩短正式正文；资料仍在启动时组装读取，完整库256MB上限保留，不宣称无限容量或磁盘按需加载。
8. **正式签名与公证流程**：新增Tools/notarize-mac.sh，在新输出目录中复制已有APP，检查指定的有效Developer ID Application证书和钥匙串公证配置，再正式签名、提交Apple公证、检查Accepted结果、装订并验证票据、执行系统评估，最后生成公证版ZIP。缺少条件或未通过检查立即停止，不把失败标为成功，也不覆盖原本机签名包。不提取、保存或打印密码。该流程只有取得实际Apple回执并通过系统验证才算完成公证。

## 更新与回退

- 更新前仍建议在旧版导出完整备份，退出旧版后替换应用。
- 2.7首次写入设置最低读取版本27，拆分存储版本4；2.6及更早版会进入保护状态。回退必须使用升级前备份，并另外保留2.7产生的独立草稿及历史，不能让旧版继续写新版资料目录。
- 不要单独复制scholar-data.json索引作为备份；保留整个数据目录，或使用完整JSON/工作包。原外部文件继续独立备份。
- 支持macOS13及以上，Apple芯片/Intel通用版；KongFolio继续沿用文稿目录0.22系列联动目标。
