# KongScholar 3.4.0

2026-10-25 · 第31次构建 · macOS13+ · Apple芯片 / Intel通用版

本版完成此前24项建议的剩余第18、19、20、21、23、24项，连同3.0—3.3累计完成24项。以下说明为具体实现范围，不代表不受容量、文件格式或人工核验限制。

## 选定材料与发放版本

18. **限定证据包**：书稿/论文 → 专题与课程材料包。新建“专题证据包”，关联当前项目的章节或论点，填写对外主题与范围说明。逐条选择史料原文、出处、PDF物理页及对外提示；可只选原文或只选PDF。摘录须逐字出现于原文，不自动输出个人解释、反证判断或其他未选记录。生成预览会核对PDF当前内容指纹，并真正抽取指定页；确认后固定版本，再导出ZIP。ZIP仅包含Markdown说明、所选PDF页和文件校验清单，不包含完整研究库JSON或本机路径。
19. **课程阅读包**：教学与指导 → 同一入口，新建“课程阅读包”，可关联课程周次。每条填写阅读名称、正整数顺序、阅读提示和讨论问题；使用上移/下移调整相邻条目。选材可组合共享史料和当前项目的多个PDF页段。切换材料包或项目后清空上一份的版本名称与临时预览，按用途选择默认范围，避免混用名称。
20. **学生材料版本管理**：课程包选择学生版或教师版，填写如“第一课·学生阅读·第一版”的名称。教师提示只进入教师版；学生版不自动包含教师提示、史料私人判断或全库其他记录。讨论版亦不输出教师提示。确认保存的版本固定当时文字、出处与实际PDF页字节，后续材料变化仅提示当前选材变化，旧版本保持，可按旧内容重新导出。版本为只读快照；修改选材后另建新版本，不覆盖原发放版本。每次成功导出记录文件路径、内容指纹和时间；路径回执保存失败会提示，但已固定版本仍保留。

PDF抽取移除注释层，不保留原文档的书签及整份文档属性；PDF页面自身已有的文字、图像和痕迹仍由使用者检查。说明中的对外字段须人工预览，不自动判断哪些由您主动填写的内容适合对外。

每份包最多50条选材、合计200页PDF、32MB文件内容；单个原PDF或KongFolio容器64MB以内，页码最高2000且须在实际文件范围。Markdown说明上限2MB。全库最多500份材料包、5000条选材、2000个固定版本，每包最多300个版本，每个版本最多100次导出回执，完整研究库仍限256MB。固定PDF副本会占用本机资料空间。当前输出为Markdown与PDF组成的ZIP，不自动生成Word讲义或发送给学生。

## 会后行动与下次接续

21. **会谈行动追踪**：书稿、论文及教学与指导 → 会谈后续行动。从已有指导准备单登记，或直接填写普通学术讨论/会谈的名称和日期。记录负责人、期限、关联章节、具体行动与完成标准，状态为待办、进行中、受阻或已完成；受阻或完成必须填写实际原因/结果。更新保留旧状态、负责人、期限、内容及结果历史，每条最多100次；全库最多2000条。

可将行动转为研究任务，重复点击关联同一任务，不重复建立。任务与行动分别核定完成状态，不因创建任务或任务完成而推定行动已完成。同一指导论文的未完成行动自动列于下次指导会谈准备单下方；普通讨论行动按项目在行动页集中接续。不会自动发消息、邀请参会或更新外部日历。

## 附件迁移与备份恢复验证

23. **扩大带附件迁移**：备份中心 → 带附件完整迁移。完整正式资料之外，可明确勾选指导原稿、索引PDF、关联KongFolio项目容器和已记录的交稿文件。先检查各文件内容身份与预计原始容量，再导出；缺失、内容不符或超限停止所选范围导出。同一内容按指纹去重。每次最多200个关联，单文件64MB，整包256MB（预留清单空间）。

迁移包格式升级为2；恢复验证继续兼容旧格式1。独立恢复时，原始PDF、KongFolio、指导原稿和交稿路径重新关联到演练目录中的副本，内容身份保持。未选外部附件保留旧路径并计入未收入数量，不声称迁移完成；未支持或超出容量的外部文件须另行保存。KongFolio有PDF指纹时核对文档编号及PDF内容；无指纹的旧关联仅核对文档编号，再固定本次容器字节，不推造历史指纹。
24. **备份可验证性**：今日工作 → 备份恢复验证，亦可从备份中心进入。选择完整JSON、工作备份、新旧迁移包或本机快照，再选择验证位置；始终新建独立目录，当前研究库保持。原生存储保存后读回并比较完整资料，核对迁移包内附件内容及固定材料文件，记录各类数量、章节正文指纹、脚注数量、所带与未带外部附件数、工作备份草稿数。随后执行界面结构校验并显示缺失关联数量。恢复目录中保存完整JSON、独立资料库及“恢复验证报告.json”。

验证只证明所收入文件可读取、内容可比对和结构可检查，不代替历史判断、逐字引注校对或外部附件人工核查。普通JSON/快照不自动携带外部PDF；工作备份沿用已有表单草稿范围，独立写作窗口未提交草稿及待补记导出回执仍须先保存、补记或另行保留整个资料目录。未采用OCR候选仍仅在当前会话。恢复验证不会自动替换当前库或把草稿导入当前库。

## 保存与发布

最低读取版本34，拆分存储版本10。首次写入前建立并核验3.4专用完整升级备份；3.3及更早版不能继续写入新版资料目录。更新前请主动导出完整备份；回退须使用升级前备份并另存升级后新增内容。新材料版本及会后行动历史进入受校验归档与正式资料备份。

研究、书稿、学生资料、PDF、图像、附件、草稿、材料包和备份仅保存在本机。GitHub只同步APP源码、合成测试及版本说明。未修改KongFolio，继续联动文稿目录中的0.22系列；本版兼容文档编号大小写表示，不改变文档身份。
