# KongScholar 3.0.0

2026-10-25 · 第27次构建 · macOS13+ · Apple芯片 / Intel通用版

本版完成新一轮24项建议的首批6项：第1、3、4、5、7、22项。其余18项保留为后续计划，未在本版实现。

## 日常入口与跨项目待核

1. **日常入口精简**：左侧集中为今日工作、书稿、论文、资料、教学与指导，上方显示对应常用操作。既有个人工作区、所有工具搜索、自定义设置继续保留；项目选择与工作区切换相互独立。页面不会自动改变项目类型。
3. **跨项目待核清单**：今日工作 → 跨项目待核清单。汇总已有正文/脚注检查、失效正文关联、未回应意见、反证处理、来源变更、缺失关联、逾期任务与变动后的交稿核验。清单自己的项目筛选独立于上方当前项目，可同时查看两部书稿和论文；打开其他项目的处理位置时先切换到对应项目。按已填写任务/项目截止日期排序，每页50项，同一检查键去重。不同性质的问题可分别出现；并非对全部正文进行语义审查。

## 段落关联与修复

4. **稳定段落编号**：在保存当前章节时，为按空行分隔的段落建立本机编号。唯一且文字完全不变的段落，在同章移动或前后新增段落时保留编号。正文未变时保留既有编号。改写、拆分、合并、重复段落在修改后取得新编号，不凭相似度自动认定身份。每章最多20000段，超出时阻止保存并保留修改。旧资料不会只因打开而批量改写，第一次保存时建立编号。
5. **正文关联修复**：书稿 → 正文关联与修复。检查书签、段落作用、问题回应、反证处理、图表位置及带正文锚点的返回批注。显示原文字、原段落编号及当前正文候选，可按文字查找，每次最多30个候选。即使锚点短句还在，原段落上下文改写也会列为待核；书签和段落作用定位同时提示复核。候选只按文字重合排列，不能证明含义或论证相同。确认的新原文必须在本章唯一出现，填写理由后保存旧位置、新位置和时间；每记录最多100次历史。预览后正文或记录变化会拒绝保存，失败保留当前输入。跨段锚点仍可按唯一原文定位，但不绑定单段编号。更换章节须编辑原记录；不会改写冻结稿、交稿快照或自动确认反证依据变化。

## 实际交稿与记录恢复

7. **实际交稿文件检查**：书稿/论文 → 实际交稿文件检查。按当前项目已保存的引注和排版方案生成真实Word，检查生成的OOXML中实际写出的正文、作者、摘要、关键词、参考文献、附录、脚注及缺失脚注标记，显示文件指纹。作者填写但未启用扉页时明确显示未输出。可以打开系统Quick Look预览这份生成文件，再保存同一预览载荷；相关资料变化后须重新生成。Quick Look可能省略页下注和分页，仅供快速查看；完整排版须保存后用文字处理软件核对。其可用性及最终分页依本机系统、字体及接收方软件而定。图像嵌入、可编辑表格和图表自动编号尚未实现；图表目录不能视为已放入正文。检查结果不自动代替人工材料核验，也不证明引注内容准确。
22. **跨次恢复交稿记录**：所有工具 → 导出记录恢复；首页也提供入口，重启时提示已有待核回执数量。在Word或含Word的阶段包实际写出前，先将稿次、实际导出正文与脚注、当时意见状态和目标文件指纹保存为独立本机回执，再写文件。取消文件选择不留成功记录；回执无法保存时停止导出，不先写外部文件。文件写入后、正式交稿历史补记前退出，重开可核对并补记；正式历史已保存但回执未清理时，按稿次去重后清理，避免重复记录。只有保存到资料库的快照与回执一致，才清理回执。文件移动、缺失或内容改变时保留待核，不能自动补记为已核文件。

所有新交稿历史另存当时文件路径、字节数、文件指纹和实际内容检查结果；路径与指纹描述导出时状态，不持续监控外部修改。章名重复时按明确章节编号记录来源；按项目样式重编脚注编号时仍保留原脚注关联。

## 本机保存与边界

- 最低读取版本30，拆分存储版本7。首次写入仍先建立并核验3.0升级前专用完整备份。2.9及更早版不能写入此版本资料；回退须使用升级前备份，并另行保存新增工作。
- 导出回执在资料目录的`export-outbox`，最多100份、单份64MB、总量256MB；达到上限时停止新导出，先处理已有回执。逐次核对文件内容最多512MB，未完成的显示待核。损坏回执不会自动删除。
- 尚待补记的回执独立于正式研究库，普通JSON和现有工作备份不包含它们；迁移前先完成补记，或另行保留整个资料目录。Quick Look预览副本在`export-previews`，最多100个、合计256MB，达到上限停止生成新预览，既有导出文件保留。
- 研究资料、稿件、PDF、学生资料、附件、独立草稿、导出回执和预览副本均留在本机。GitHub只允许源码、合成测试和版本说明，继续排除小写`sources/`及资料目录。
- 本轮未修改KongFolio或正式研究资料库；联动目标继续为文稿目录的0.22系列。

Mac隔离合成库完成跨项目意见进入、段落移动编号保留、改写后人工修复及历史保存、实际Word检查与Quick Look预览。人为使正式历史写入失败后，外部文件及回执均保留；退出重开显示待核数量，经文件指纹核对补记为第二份独立交稿，回执清理，无重复稿次。实际保存Word与预览载荷的文件指纹一致，样稿4页使用本机中文字体渲染并逐页检查，正文、中文、摘要、参考文献、附录与页下注完整。专用升级备份与最初合成库逐字节相同，未打开正式研究库。

本机安装包、源码包、GitHub远端同步和Apple公证分别核验。缺少远端连接/登录或正式签名证书时，不标示发布成功；具体结果见本版源码回执和验证说明。
