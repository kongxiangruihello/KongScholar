# KongScholar 2.8.0

2026-10-25 · macOS 13+ · Apple芯片 / Intel通用版 · 第25次构建

落实上一轮30项建议的第二阶段（第9—18项），衔接史料原页、整理文本、研究判断与查找任务。第1—8项已在2.7交付，第19—30项仍待后续实施。

1. **PDF与正文并排（第9项）**：章节写作台上方“打开史料并排阅读”，或“所有工具 → 史料阅读与正文并排”。先使用“本机PDF全文检索”导入PDF或从既有KongFolio定位建立索引，再在本窗口左侧打开原页；右侧可以进入写作台，保留原页及史料面板。左侧可翻页、调整分隔线和收起。每份PDF单独保存物理页位置，返回写作台恢复原章节光标和编辑区滚动位置。不会自动在启动时打开外部文件。
2. **PDF页码映射（第10项）**：“页码映射与摘录覆盖”按封面、序言、正文添加不重叠的物理页分段。连续阿拉伯数字模式填写起始印刷页和可选前缀；罗马数字、中文数字、封面或无页码页面使用逐页标签，一页一行。所有映射须填写人工核对依据，不根据物理页号擅自推定印刷页。
3. **跨页摘录（第11项）**：在并排PDF中选文字，再点“将PDF所选文字转为跨页摘录”；或手工建立摘录。表单可调整连续起止页，保存前填写定位核对依据。每条摘录记录索引编号、文件校验值、文件位置、KongFolio文档标识、各页当时的印刷标签和选文区域。可手填区域：物理页 | 左,上,宽,高，均为0—1且不能越界；空白代表未指定区域，使用整页定位。扫描PDF可手工录文或衔接原有OCR流程。新脚注包含每页出处，完整区域与文件校验值留在资料和引文签名中，不把长校验值加入学术脚注。
4. **摘录覆盖检查（第12项）**：同页可有多条摘录，覆盖页数按去重物理页统计。另行手工记录已读、已核或存疑及依据，不把“有摘录”视为已经核对。逐页表每组50页，可导出完整覆盖表；暂无摘录且未记录阅读状态的页单列为尚未处理。索引文字层本身不算正式摘录。
5. **OCR疑字集中清单（第13项）**：汇集现有逐行校订中人工标记的存疑行，可按原字、校订字、史料和辨析筛选，显示影像与物理页，返回原影像及该识别行。解除存疑仍通过原校订流程，保留本次依据和OCR历史。列表预览前200行，导出含本次全部筛选结果；不会把机器置信度直接当成正确与否。
6. **原件与整理稿分层（第14项）**：PDF或证据影像保留原件，史料卡分别记录原文摘录、标点整理稿、通行字转录稿和个人释读。编辑史料时明确选择新引用采用的层；非原文层须填写内容与整理依据。写作台显示选用层，新插入的引文采用该层，脚注注明整理层和依据；既有正文、脚注、冻结稿和交付稿保留插入时内容。各层或定位变化会进入既有史料变更复核。
7. **原文译文分段对齐（第15项）**：每段关联两条独立史料，从各自原文中填入段落锚点，记录对应、增译、省译、概念替换或待判断及依据。增译的原文侧、省译的译文侧留空。原段后来修改或重复时显示定位失效/不唯一，保留既有锚点供复核；不自动推定翻译关系或替换文字。
8. **史料版本取舍（第16项）**：为每次使用场合记录至少两种候选版本、选用版本、关联章节、取舍理由及未选版本的价值/限制。同一史料可用于多个场合的不同判断；此记录不会合并原刊、转载或重印史料，也不自动替换正文旧引文。
9. **证据可靠性说明（第17项）**：作者归属、年代判断、传播范围、文本完整性分别填写依据和不确定性，并说明可支持的判断及解释限度，关联所用其他证据。未核事项可明确写“待核”及待查内容，不以单一分数或字段齐全代表材料可靠。
10. **待查线索转检索任务（第18项）**：记录缺期、缺信或出处待核的拟查馆藏、检索词、变体和范围，一键接入研究任务；同一线索已有未完成任务时不重复创建。逐次记录实际检索日期、馆藏、检索式与范围、未检出/找到候选/已找到并核对/访问受限/待继续，以及结果说明。未检出只表示已查范围；APP不会因此声称已完成外部检索。研究任务本身也不自动联网检索。

## 资料与更新保护

- 所有新数据仍在本机。源码同步仅白名单APP源码、合成测试和版本说明；研究资料、学生资料、PDF/影像、稿件、草稿、备份均不上传。
- 首次写入2.8前继续核验升级前专用备份；资料最低读取版本升至28，拆分存储版本5。2.7及更早版不能继续写入此目录。回退须使用升级前完整备份，另行保留新版资料与独立草稿。
- 页码映射修改不回写已有摘录的页码快照；引文检查会提示复核。确认新的定位后，编辑摘录范围或定位核对依据再保存，明确建立新的定位快照。已有正文脚注仍须逐条人工更新。
- 单条跨页摘录为连续1—100页；单段映射最多2000页；范围均不能越过对应PDF。原有PDF索引上限256MB/2000页、文字索引12MB保留。总资料完整备份256MB上限保留。
- 覆盖表只统计与原索引编号及文件校验值匹配的跨页摘录；旧单页KongFolio史料不擅自归入某份新索引。需建立跨页定位后才进入本表。
- 外部PDF、KongFolio项目及稿件附件仍须独立备份；完整JSON/工作备份保存的是资料和定位，不能代替外部原件。
- KongFolio沿用文稿目录0.22系列目标及既有稳定文档定位，不选择旧版APP，不修改其工程文件。
