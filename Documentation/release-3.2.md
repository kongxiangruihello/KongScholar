# KongScholar 3.2.0

2026-10-25 · 第29次构建 · macOS13+ · Apple芯片 / Intel通用版

继续实现新一轮24项建议的第12—17项，连同3.0、3.1累计完成18项。剩余第18、19、20、21、23、24项继续列为后续计划。

## 返回稿与逐项回复

12. **Word文字修订接续**：书稿/论文 → Word文字修订接续。读取本机DOCX正文段落中可辨认的插入、删除、作者及时间，分别显示该段局部修改前后文字。确认稿次、勾选修订并人工选择章节后，接入同行意见收件簿，仍为待判断、待处理；重复读取同一文件同一修订不重复建立记录。读取和接入均不改写Word或章节正文。传统/新式批注沿用原入口，亦可转入当前返回稿的文字修订页。

仅支持主文档段落中的文字增删。移动、表格内修订、格式与段落标记变化、绘图/文本框等单列未接续提示，不声称还原完整修订前后文件。含脚注或域等复杂内容的修订另提示须回Word核对。XML上限12MB、2000条文字修订、20000个段落、嵌套256层；重复的上下文总量另限12MB，超限拒绝而不截断导入。异常XML及DTD/实体声明拒绝读取。实现依据Microsoft的[插入文字定义](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.insertedrun)及[各类修订说明](https://learn.microsoft.com/en-us/office/open-xml/word/how-to-accept-all-revisions-in-a-word-processing-document)。

13. **审稿逐项回复材料**：同名页面逐项选择原意见，填写对外回复、接受/部分接受/暂缓/不采纳、修改章节、唯一原文片段、位置说明及采用证据。接受或部分接受并标为已核时，原文片段须能唯一定位于当前正文。原意见、正文或证据后改后提示重新核验；全部已登记回复核定后，才能导出当前项目的Word/Markdown回复材料。材料固定当时原意见、对外回复、修改片段及所选证据的出处摘要，不自动带出内部判断、反证分析或处理理由，也不会自动改变原意见的回应状态。作者须自行检查对外回复中主动填写的内容。导出沿用交稿记录与待补记回执保护；未登记回复的其他意见不自动纳入。全库最多2000条回复，每条最多100次历史，对外回复50000字以内。

## 写作、识读与版本核对

14. **正文与脚注即时预览**：章节写作台 → 显示正文与脚注预览。编辑正文后约0.18秒更新，按首次出现顺序排列本章脚注，重复标记沿用注号，缺失脚注明示；切换预览不改正文。预览上限80000字符、200条不同脚注，每条出处显示最多2000字符，超限明确提示，实际编辑与导出不因此截断。图表暂显示正文标记，不模拟Word分页与最终页下注布局。

15. **个人识读词表与候选**：资料 → 个人识读词表与候选。按项目登记人名、刊名、旧称、常见误识和核定依据；可在现有文字中查找登记的误识字串，或明确点击后将该项目词表用于一次本机影像识读。新识读结果单独展示，填写采用依据后才写入校订稿，标为待校并保留原始OCR与修改前后历史；史料原文和原图保持。未采用候选仅在当前会话中暂存。词表识读会启用系统语言校正，可能改变旧字词，不能据此视为逐字校准；旧的无词表识读路径保持。此选择依据Apple说明：[customWords在关闭语言校正时不生效](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/customwords)。全库最多500词、每词80字符、总UTF-8文本32KB；查找最多500处，每次展示100处。

16. **跨版本页码对应**：资料 → 跨版本页码对应。选择同一项目的两个不同PDF，逐行填写“左物理页 | 右物理页”和核定依据，可登记一页对应多页。按登记的页对分别打开两版原页；没有登记的页面不推算、不插值。对应表固定两个PDF的内容指纹，重建或更换PDF后旧表保留并停止沿用，应另建新表。全库最多500表，每表最多2000组页对，物理页上限2000且须在实际文件范围内。PDF文件仍需自行保留；普通JSON只包含关联与对应表。

17. **逐条引文文本层选择**：书稿/论文 → 逐条引文文本层选择。针对单条脚注分别选择原文、标点整理、通行字或个人释读，填写采用依据；引用须出现在所选文本层，整理层另须已有史料整理依据。新引文可以连同摘录插入正文；既有引文换层只更新该脚注的快照，正文引用文字须自行修改。史料的默认引用层不随单条选择改变。当前所选层后改会提示复核，修改默认层或未选层不误报。逐条选择与史料快照进入交稿历史，整稿冻结版保持冻结时的脚注选择，不借用后来的当前脚注。首次插入仍待逐字核对，人工勾选后才标为已核。

## 保存与迁移

- 最低读取版本32、拆分存储版本9。首次写入前建立并核验3.2专用完整升级备份。3.1及更早版不能继续写入本版资料；回退须使用升级前备份，并另行保留升级后新增内容。更新前请主动导出完整备份。
- 新回复、识读词和页码对应记录进入受校验存储及正式资料备份。完整库上限仍为256MB。独立窗口未提交草稿、独立导出回执及未采用识读候选等仍有各自边界；迁移前先正式保存草稿、补记回执，必要时保留整个本机资料目录，勿只复制索引文件。
- 研究资料、书稿、学生资料、PDF、影像、附件、草稿与备份只留本机。GitHub只允许APP源码、合成测试与版本说明。未修改KongFolio，目标继续为文稿目录中的0.22系列，精确联动使用0.22.1。
