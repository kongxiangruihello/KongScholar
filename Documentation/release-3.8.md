# KongScholar 3.8.0

本版完成8项个人学术工作流改进，以多项目日常推进、日历安排和章节研究为中心，不加入教学内容。

1. 工作台项目卡片支持拖动排序、上移/下移、折叠与每日重点；排序和折叠持久保存，重点每天单独选择（最多5项）。自定义顺序优先于旧置顶顺序。
2. 在项目卡片直接记录今日实际进展、下一步与卡点；进展进入独立日志，下一步和卡点同步到项目，先前日志保留。输入先暂存本机草稿，正式进展须点击保存，草稿跨启动保留。
3. 统一学术周视图汇集项目、任务、投稿、讲座及独立安排，可按项目筛选、翻周、点击小时空白格建立安排。按小时分格，精确分钟和跨度以标签为准；跨日按当天分段。
4. 日历拖动改期先预览再确认，保留原值、目标、原因与时间，支持撤销。原项目记录仍是日期来源；任务计划与历史一起更新。预览过期拒绝写入，撤销拒绝覆盖后续编辑，批量系列调整原子恢复。
5. 创建每周/每月有限系列（2—200次，最多5年），先列出日期；月末缺日跳过。每次可独立编辑，或预览调整本次及后续，并可明确选择统一名称、时段、地点和说明。iCalendar支持有限DAILY/WEEKLY/MONTHLY、COUNT或UNTIL、每周非序数BYDAY、与首次同日号的BYMONTHDAY、EXDATE和单次RECURRENCE-ID（无RANGE）。单系列最多200次和5年，展开后每次最多500项。复杂、无限、RDATE/EXRULE及不匹配例外明确列出原因；不猜测部分规则。导入后保留系列关联，导出为独立事件，不重新生成RRULE。
6. 专题研究线索板关联问题、论点、章节、史料及反证，按待证/支持/争议/暂缓查看。可建立“何以为士”初始组织线索，再由本人重命名与补证；不自动产生学术结论。
7. 章节研究包集中核心问题、拟论证观点、所选摘录、反证和待核出处。预填来自现有记录，保存前核对；原文、个人解释与限度分别呈现，不自动改写正文或原始材料。
8. 阶段回望按日期及项目汇总进展、章节版本、史料使用核对与活动记录，可编辑摘要、补充判断和下周计划。保存为研究周报并保留来源快照；后续资料变化不覆盖原稿。

离线帮助扩充至32个主题，新增上述功能说明。最低读取版本38、归档格式14；新记录及来源历史进入完整备份，升级前保留原资料快照。旧版不应继续写入升级后的资料库，回退应使用升级前备份。

iCalendar继续是手动文件交换，不是系统或云端实时同步。不执行提醒、邀请、参会人、附件或链接。不同时区的日程不自动比较时段重叠，需按标签核对。格式参考：[RFC5545](https://www.rfc-editor.org/rfc/rfc5545)。

GitHub仅同步源码、合成测试与版本说明；研究记录、PDF、附件与本机备份不上传。macOS13起，Apple Silicon/Intel通用构建；本地签名，尚未Apple公证。

验证：31组JavaScript回归测试、124项Swift测试通过，包含旧版兼容、独立备份恢复、中文日期与例外、保存失败回滚、改期撤销保护、进展草稿和研究周报来源快照。Mac界面已实测项目与日历拖动、卡片进展、线索与研究包、周视图新建、系列预览/创建、例外导入及研究周报保存。Intel完成交叉编译，未单独实机运行。
