# KongScholar 3.7.0

本版为个人学术日历增加右键操作与本地 iCalendar 文件交换，并提供可搜索、离线的详细帮助说明。继续围绕著作、论文、讲座和个人研究工作组织内容。

## 日历右键操作

- 日期空白处：在当日新建独立学术日程，或导出当日事项。
- 具体事项：编辑原记录与日期、复制为独立日程、单项导出、打开所属项目。
- 独立日程：标记完成、重新打开、移入回收站。研究任务完成沿用原任务核验；项目本身不会被右键日程操作删除。
- 支持键盘 Shift+F10、方向键、Home/End、Esc 与 Return。跨日事项在经过的日期显示；凌晨00:00结束不占用结束当天。

## iCalendar 文件交换

导入 `.ics` / `.ical` 先显示预览、条目处理方式及未导入原因，确认后原子写入。可选择独立日程或归入个人学术项目。UID 与内容用于识别重复；来源更新须明确选择；本机已经改动时只允许保留或另存新日程。更新保留原值历史，预览后资料变化须重新检查。已有项目事项导出后再导入不会新建第二份。

导出支持本月、当前显示范围、某日或单项；勾选范围、生成实际文件预览后再保存。默认排除独立日程的说明正文；项目说明、研究任务正文、讲稿、研究正文和附件始终不自动带出。相同事项在同一资料库重复导出保留 UID，资料库使用独立标识。

支持 iCalendar 2.0 单次 VEVENT、UTF-8 中文与折行、全天、跨日、UTC、可识别 IANA TZID、浮动时间、DTEND 或 DURATION。导入按当前 Mac 时区转换并保存，带时间导出使用 UTC；全天按 RFC 5545 的不包含结束日规则转换。日历中不同时区的事项不自动比较时段重叠，需按标注时区核对。

每次导入500项以内、2MB以内；导出最多5000项且2MB以内；单条跨度最多366天，按分钟记录。重复规则及例外不展开；未知时区、非零秒、无结束时间或无效日期列明原因。自定义 VTIMEZONE 不解释，使用可识别系统时区；会议邀请与取消消息 METHOD 不处理，提醒、参会人、附件及链接不会执行。本版是手动文件交换，不是系统或云端实时同步。

格式参考：[RFC 5545](https://www.rfc-editor.org/rfc/rfc5545)。

## 详细帮助说明

25个主题：定位与快速开始、侧栏与项目范围、多项目接续、阶段与阻塞、任务、文献与摘录、PDF/KongFolio、论证证据、目录正文、引文脚注、交稿、Word返修、投稿、讲座、成果、履历、日历、右键菜单、iCalendar、备份、恢复、草稿回收站、隐私、快捷操作、排查问题。

应用内可搜索主题、查看步骤及常见问题，日历页面提供对应帮助入口。Mac“帮助”菜单打开独立窗口，保留主窗口正在编辑的表单。同一份结构化主题生成安装包中的离线 HTML 说明，支持搜索、目录、深浅色及窄窗口阅读。

KongFolio 衔接目标继续为“文稿”目录中的0.22系列，按0.22.1桥接约定核对；不引入教学工作流。历史教学相关记录继续只读保留并进入完整备份。
