# KongScholar 2.4.0

发布日期：2026年10月24日。支持macOS13及以上，Apple Silicon / Intel通用版。

## 本版20项

1. **扩大容量**：当前资料索引与冻结稿、交付历史、章节版本、问题演变、影像等较大内容分开保存。当前索引上限64MB，完整资料上限256MB。归档和索引均有校验；损坏或缺失时进入读取保护，保留文件并允许通过完整备份恢复。旧归档不自动清除。
2. **备份健康**：设置与工具 → 容量与备份健康，检查最近快照、结构和编号、记录数量与空间占用。可选择本机其他目录或移动硬盘额外备份，到期间隔与本机备份相同，手动和退出前立即检查。硬盘未连接时等待重试，不创建替代目录。额外备份按内容去重，读取校验后报成功，不自动删除。
3. **回收站与撤销**：未被引用的记录先移入回收站，可恢复；本次打开后保留最近20次、每次不超过100条且快照小于2MB的资料撤销，连续两秒内同记录修改合并。后续独立变化会阻止覆盖。文字框⌘Z继续撤销输入。回收站最多300条，可先导出可选择恢复的回收记录归档，再释放容量；取消导出或保存失败时保留回收记录。
4. **操作面板**：⌘⇧K打开全局操作面板，搜索页面、新建操作、当前项目章节与资料，以及各项目入口。⌘K仍为全局内容检索，⌘⇧P仍为项目快切。
5. **精力预算**：工作台 → 每周精力预算，按周一为各项目分配计划小时、手工记录实际投入，并填写每周可用小时。任务可估时、指定计入项目；共享任务只计一次。显示分配和已排任务是否超出预算，不自动重排工作。
6. **整稿通读**：写作 → 整稿连续通读，按项目目录连读正文及脚注，跳转章节、回写作台修改或记录章节意见。长稿分批显示，可继续加载，不截断保存内容。
7. **段落与交叉引用**：通读时保存段落书签，以原文锚点重新定位。段落移动仍可寻找，改写或多处相同会提示。建立内部引用后可向引用章节保存的光标位置插入参见文字，无位置时插入章末。题名变化会提醒，不自动改写既有正文；重复插入保留两处，请自行整理。
8. **参考文献与引注一致性**：依据正文实际使用的脚注整理关联书目，列出未匹配文献及脚注文本变体。页码不同也可能产生变体，须人工判断。可导出待补清单或含参考文献表的Word；格式沿用现有档案，仍须按期刊要求审定。
9. **书目交换**：资料 → RIS与BibTeX书目交换，读取UTF-8文件或粘贴文本，预览新增或补齐空字段，保留已有非空修改和考证。按题名、作者、年份归一匹配，多个相同候选跳过。新书目保留原始交换字段，不执行TeX宏；复杂宏拼接需先展开。一次最多2000条、文件不超过10MB。导出范围为当前项目文献档案，含书目说明，不包含史料原文或研究札记。
10. **专题集**：保存关键词、人物、年代、记录类型等检索条件，或手工选择史料和文献。引用共享原记录，不复制材料。动态专题结果随当前项目范围和资料变化更新。
11. **影像证据**：从关联KongFolio项目指定物理页，或本机PNG / JPEG / TIFF影像框选区域。保存截图、区域百分比、来源定位快照及人工填写的印刷页码。仅读取KongFolio项目，不修改文稿中的原APP；无需替换为其他版本。可请求回KongFolio核对来源页。
12. **OCR校订**：使用Mac本机Vision识别框选影像，原始OCR、校订稿、依据、状态和历史分别保留；不覆盖史料原文。竖排、异体字和识别顺序须人工核查。离开或退出前保存校订；缺少依据或写入失败时保留当前窗口。首次识别可能需要等候。每张影像最多300次校订、PNG不超过8MB。
13. **多版本校勘**：选择3—12条史料与底本，保存当时文本及出处快照，按行比较异文并记录判断。后续史料修改不改写快照，更换整组材料须另建校勘组。每份差异比较前500行、10万字，完整文本仍在快照中；长篇建议按篇分组。
14. **上下文索引**：从已录入史料原文逐处寻找词语，显示前后文，支持项目、人物和年代筛选，并建立概念用例。最多30个检索词、2000处结果，界面显示前300处，导出保留本次全部结果。不检索外部PDF，也不自动判定词义。
15. **来源独立性核对**：根据已记录的转载、翻译、节录和转引关系，将论点支持与反证材料按共同来源分组，待核关系另列。未记录同源关系不代表独立，分组数量不证明论点成立。
16. **论证分层**：在论证卡片分别填写史料直接陈述、解释步骤、待证假设、适用范围及推理依据。写作 → 事实解释与假设分层，集中审查上述关系，事实身份由您核定。
17. **投稿档案**：记录目标期刊、格式要求、状态和期限，关联同一项目的冻结稿及交付记录，截止事项可转任务。按自填关键词检查正文和脚注中的匿名线索；篇幅为应用字符计数，须按期刊口径复核。不检查Word属性，也不自动删除作者或史料署名。
18. **独立审稿**：私人阅读笔记、给作者的意见、给编辑的意见与处理建议分别保存。按对象预览再导出Markdown / Word，作者版不包含编辑意见和处理建议，两版均不包含私人笔记。不代您发送。
19. **学期课程**：将研读课关联到1—48周的学期，按周安排主题、材料、作业及课后反思。预览并导出学生版或教师版学期材料；学生版省略专用教师提示与反思，公共字段仍须人工检查。
20. **论文指导**：按论文保存阶段、会谈、指导意见、下一步及日期，可转指导任务。各稿次正文 / 摘要独立保留，新正文另建稿次。可关联PDF、Word、Markdown或文本原稿，保留文件链接和校验值，打开时提示是否变化。指导纪要不包含私人会谈笔记。

## 更新和备份

升级前先从旧版导出完整JSON备份，再退出旧版、替换APP。首次启动仍保留升级前快照。本版读写格式升级后，旧版将进入读取保护；不要用旧版继续写入新资料。回退时请恢复升级前完整备份。

数据目录仍为本机Application Support中的KongScholar。scholar-data.json从本版起可能只是索引，archives目录包含历史及影像，两者须一起保留；不要单独复制索引作为备份。应用导出的完整JSON和自动 / 额外快照会重新组装为自包含资料，包含影像和全部历史，可独立恢复。外部指导稿件只保存链接，原文件须另行备份。归档文件及额外备份不自动清理，请留意磁盘空间。备份仅在APP运行时执行。

GitHub公开仓库仅发布APP源码、合成测试和版本说明。书稿、史料、影像、意见、学生资料、原稿附件和备份不上传。APP不保存GitHub凭证，不提供研究资料跨设备云同步。

安装包为本机签名，未经Apple公证。

## 验证

34项Swift测试和16组JavaScript测试通过。测试覆盖分拆存储、索引与归档校验、独立完整备份恢复、损坏归档修复、旧版写入保护、额外备份断开处理，以及新增界面逻辑。

使用隔离合成资料完成Mac验收：KongFolio关联页影像截取、本机OCR、原始与校订文本分别保留、缺少校订依据时阻止离开、完整备份与重新打开、书目导入、段落引用、多版本校勘、来源分组、课程与论文指导、审稿分对象导出、回收与撤销。含正文、脚注和参考文献的Word样稿四页已渲染并逐页检查。验收未改动真实研究资料或文稿目录中的KongFolio。
