# KongScholar 3.5.0

KongScholar 是供本人使用的个人学术工作台，以著作、论文、讲座与学术报告、研究资料为基本内容。授课、备课、课表与学生管理退出日常工作范围。此定位取代旧版说明中的教学产品方向；下方历史版本说明只用于查阅旧行为。

## 本版调整

- 五个主入口为今日工作、著作、论文、讲座与学术报告、研究资料。保留紧凑图标导航、灰白配色和左下方自动备份状态。
- 今日工作台跨项目汇总学术待办，显示正在推进的个人学术项目、近期报告及下一步准备事项。旧教学项目、备课任务与指导行动不进入今日安排、普通列表或全库检索。
- 新增讲座与报告记录：形式、准备阶段、日期、时间与时长、会议或主办方、地点、摘要、提纲、讲稿、下一步和报告后反思。日期可稍后填写；须归属一个个人学术项目。最多2000条，讲稿每条最多50万字符，其他长文本各10万字符。
- 可导出单份Markdown讲稿，包含题目、会议信息、摘要、提纲与讲稿。后续反思和下一步不随讲稿输出。暂不提供幻灯片编辑、会务安排或日历自动同步。
- “学术材料包”支持专题证据包及学术报告资料包。选择原文、出处与PDF原页，预览后固定讨论版本并导出ZIP；不自动带出个人解释、反证或旧教师提示。容量和内容校验沿用3.4。
- “学术交流后续行动”可直接登记具名讲座、会议或同行讨论，记录负责人、期限、结果和状态历史，并转为研究任务。
- 新建项目及任务类型不再包含教学与学生指导。编辑项目仍用阶段下拉菜单，已有自定义阶段保留。
- 个人偏好只显示研究方向、思考方式及写作路径；旧偏好字段保留，供完整备份兼容使用。

## 历史内容与备份

旧有教学、指导、课程材料及其固定版本按原类别只读保管，不删除或自动改成讲座。可从“个人工作区与所有工具”查找“历史内容保管”，展开查看原字段、导出完整备份，或重新导出旧材料固定版本。各类别页面最多展开前50条，长字段显示前1万字符；完整内容及全部记录在完整备份中保留。旧自定义工作区不丢失隐藏页面，编辑可见页面时仍保留历史设置。

自动本机备份、备份恢复验证、PDF与文稿目录中KongFolio 0.22系列（0.22.1桥接协议）的联动继续使用。GitHub仅同步APP源码、合成测试与版本说明；研究资料、PDF、附件和本机备份不上传。

最低读取版本35，拆分存储版本11。首次写入前由应用建立并核验3.5专用升级前备份。更新前请导出完整备份；旧版本不能继续写入新版资料目录。回退需使用升级前备份，并另存升级后新增内容。

macOS 13或更新版本，Apple芯片与Intel通用。应用为本地临时签名，未做Apple公证。
