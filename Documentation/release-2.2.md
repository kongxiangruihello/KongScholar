# KongScholar 2.2.0

发布日期：2026年10月24日。

## 同行讨论与修订

- 意见收件簿保留意见原话、作者判断、决定、理由和回应。每条意见对应一个项目，可关联章节、论点、史料及保存版本。未绑定版本时仅记录手工稿次名称，不自动保存当时正文。
- 接受或部分接受的意见可转为修订任务，重复操作打开已有任务；按项目调整顺序和日期，完成时须填写修改说明。任务完成与意见已回应分别记录。
- 修订稿交付包增加总体修改说明和意见回应表；可选择是否包含意见原话、待解决问题及论点证据、内部材料使用说明和个人札记。默认不包含后三类内部材料，引注检查始终保留。
- 交付包可逐项预览后导出ZIP，不自动发送。交付页稿次、总体说明和选项是当前会话草稿；正式修改说明请保存在意见和任务中。

## 本机自动备份

设置与工具 → 备份与恢复，可选15、30、60或120分钟检查间隔，默认60分钟；保留30、60或120份自动快照，默认60份。APP运行时每分钟检查是否到期，首次保存、关闭窗口或退出前也会检查。内容未变化时不重复创建自动快照；手动和升级前快照保留。备份中心显示最近可读取快照和错误状态，可预览恢复。

备份仅在APP运行时执行，APP退出或电脑关机后不继续后台运行。研究资料只在本机保存，本版不提供跨设备资料同步。

## GitHub源码同步

公开仓库：https://github.com/kongxiangruihello/KongScholar

仅同步APP源码与版本说明。书稿、论文、史料、同行意见、备份和安装包不上传。发布时用Tools/prepare-source-sync.py生成源码白名单，并保留.gitignore资料排除规则。提交需使用已授权GitHub连接。APP不持有GitHub凭证，研究资料修改不会触发GitHub提交；后续版本发布时继续同步源码。

## 验证与安装

23项原生测试、14组JavaScript测试通过。覆盖意见任务去重、完成说明约束、项目隔离、交付选项、备份参数与恢复往返、备份间隔及保留数量、重复抑制和失败保护。

Mac隔离合成资料验收确认讨论稿定位、意见转任务、填写修改说明并标记完成、实际导出修订ZIP、保存15分钟备份设置，以及退出前最新快照包含最新完成说明和设置。源码清单只包含代码、测试与说明文件。
